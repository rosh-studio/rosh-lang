# Block Pusher - Level Definitions
# ASCII format for Sokoban-style puzzles
#
# Legend:
#   # = wall
#   . = floor
#   P = player start
#   B = box
#   G = goal (circle)
#   * = box on goal (for reference)
#
# Grid: 8 columns x 6 rows
# Each cell = 50px

=== LEVEL 1 ===
# Simple: push box right onto goal

########
#......#
#.P.B.G#
#......#
#......#
########

Player: (1,2) -> pixel (275, 275)
Box:    (3,2) -> pixel (375, 275)
Goal:   (5,2) -> pixel (475, 275)


=== LEVEL 2 ===
# Push around wall: player must push box UP then RIGHT

########
#.....G#
#......#
#P.B.W.#
#......#
########

Player: (1,3) -> pixel (275, 325)
Box:    (3,3) -> pixel (375, 325)
Wall:   (5,3) -> pixel (475, 325)
Goal:   (6,1) -> pixel (525, 225)

Solution: Push box UP twice, then RIGHT three times


=== COORDINATE FORMULA ===
pixel_x = (grid_x * 50) + 225
pixel_y = (grid_y * 50) + 175

Grid (0,0) is top-left of play area
Play area is centered in 800x600 canvas
