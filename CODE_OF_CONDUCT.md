# Code of Conduct

## Our Commitment

Rosh is designed to make programming accessible to everyone. We are committed to providing a welcoming, inclusive environment for all contributors and users, regardless of experience level, background, or identity.

## Expected Behavior

- Be respectful and considerate in all interactions
- Welcome newcomers and help them learn
- Accept constructive feedback gracefully
- Focus on what is best for the community and project
- Show empathy towards others

## Unacceptable Behavior

- Harassment, discrimination, or exclusionary language
- Personal attacks or insults
- Publishing others' private information without permission
- Disruptive or unconstructive criticism
- Any conduct that would be inappropriate in a professional setting

## Scope

This Code of Conduct applies to all project spaces, including:

- GitHub issues, pull requests, and discussions
- Project communication channels
- Events or meetups related to the project
- Representing the project in public spaces

## Reporting

If you experience or witness unacceptable behavior, please report it to:

**Email:** info@rosh.cloud

All reports will be reviewed and investigated promptly and fairly. We will maintain confidentiality regarding the reporter.

## Enforcement

Project maintainers may take any action they deem appropriate, including:

- Warning the offender
- Temporary or permanent ban from project spaces
- Removal of contributions

## Attribution

This Code of Conduct is adapted from the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.

## Academic Context

Rosh is used in educational and research settings. We particularly encourage:

- Patient, constructive feedback for learners
- Clear explanations that help others understand
- Recognition that users come from diverse technical backgrounds
- Support for those using Rosh in teaching contexts
