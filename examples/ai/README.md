```rosh
set player.health to 100

    print "Low health!"

```

### 2. Clear Intent
```rosh
# What you mean is what you write
create object hero from player
```

## Working with AI Assistants

### Describing What You Want

**Instead of:**
> "Write a loop that increments a counter"

**Try:**
> "Create a counter that starts at 0 and increases by 1 each time, stopping at 10"

AI will generate:
```rosh
set counter to 0
while counter less_than 10 do
    set counter to counter plus 1
    print counter
end
```

---

### Getting Explanations

**Ask:**
> "Explain what this code does"

**AI will describe:**
- High-level purpose
- Each step's function
- How parts interact
- Potential improvements

---

### Debugging with AI

**Instead of:**
> "This doesn't work"

**Try:**
> "When I collision with the enemy, both the enemy handler and coin handler fire. How do I make them trigger separately?"

AI can:
- Identify the issue (generic event names)
- Explain why it happens
- Suggest a fix (unique event names per collision pair)
- Implement the solution

## AI Code Generation Tips

### 1. Be Specific
❌ "Make a game"
✅ "Create a game with a player that moves with arrow keys and shoots with space"

### 2. Describe Behavior
❌ "Add collision"
✅ "When the hero collides with an enemy, decrease lives by 1 and print the new lives count"

### 3. Ask for Explanations
After generation, ask:
- "Explain what each part does"
- "Why did you choose this approach?"
- "Are there alternatives?"

### 4. Iterate
Build incrementally:
1. "Create a player object"
2. "Add movement controls"
3. "Add collision detection"
4. "Add a HUD showing lives"

## Natural Language Patterns

Rosh syntax maps naturally to English:

| English | Rosh |
|---------|------|
| "Set X to 10" | `set x to 10` |
| "If X is less than 5" | `if x less_than 5 then` |
| "Add 1 to score" | `set score to score plus 1` |
| "When player fires" | `when fire then` |
| "Create a hero" | `create object hero` |

This makes it easy for AI to:
- Understand your requests
- Generate correct code
- Explain what code does
- Suggest improvements

## Example AI Conversation

**You:** "I want to make a simple game where a hero moves with arrow keys"

**AI:** "Here's a basic setup:"
```rosh
create object hero from player
    set x to 50%
    set y to 50%
end

print "Use arrow keys to move!"
```

**You:** "Can you add an enemy that the hero should avoid?"

**AI:** "I'll add an enemy and collision detection:"
```rosh
create object enemy
    set x to 75%
    set y to 25%
end

when collision hero enemy then
    print "Game Over!"
end
```

**You:** "Make the hero have 3 lives instead of instant game over"

**AI:** "I'll add lives tracking:"
```rosh
create object hero from player
    set x to 50%
    set y to 50%
    set lives to 3
end

when collision hero enemy then
    set hero.lives to hero.lives minus 1
    print "Ouch! Lives: {hero.lives}"
    if hero.lives less_than 1 then
        print "Game Over!"
    end
end
```
