## Problem Statement

Interactive Rosh programs that use `input` commands cannot be tested in CI/CD pipelines because they wait for user input, causing tests to hang indefinitely.

**Current issues:**
- `input` command blocks execution waiting for stdin
- No way to mock input for automated testing
- CI/CD tests timeout or hang on interactive programs
- Can't test games/MUDs in automated test suites
- Manual testing required for all interactive features

**Example of broken CI/CD test:**
```rosh
# game.rosh
print "What's your name?"
input name
print "Hello {name}!"
```

Running `rosh game.rosh` in CI/CD hangs forever.

---

## Proposed Solution

Implement a **test mode** that mocks interactive commands for automated testing.

### Option A: --test Flag with Input File

```bash
# test_input.txt contains mock inputs
echo "Alice" > test_input.txt
rosh game.rosh --test test_input.txt

# Reads "Alice" from file instead of stdin
# Output: What's your name?
#         Hello Alice!
```

### Option B: --test-input Inline

```bash
rosh game.rosh --test-input "Alice,north,attack goblin,quit"

# Comma-separated inputs fed to each input command
```

### Option C: Environment Variable

```bash
export ROSH_TEST_MODE=1
export ROSH_TEST_INPUT="Alice\nnorth\nattack goblin\nquit"
rosh game.rosh

# Reads from env var instead of stdin
```

**Recommendation:** Implement Option A (file-based) + Option B (inline) for flexibility.

## Implementation Notes

### Mock Input System

**Core implementation in `src/rosh/interpreter.py`:**

```python
class Interpreter:
    def __init__(self, output_stream=None, test_mode=False, test_inputs=None):
        self.test_mode = test_mode
        self.test_inputs = test_inputs or []
        self.test_input_index = 0

    def eval_input_command(self, variable_name):
        """Handle input command with test mode support"""
        if self.test_mode:
            # Use mocked input
            if self.test_input_index >= len(self.test_inputs):
                raise RuntimeError(
                    f"Test mode: No more test inputs available "
                    f"(needed input for '{variable_name}')"
                )
            value = self.test_inputs[self.test_input_index]
            self.test_input_index += 1
            self.output_stream.write(f"[TEST INPUT: {value}]\n")
            return value
        else:
            # Use real stdin
            return input()
```

### CLI Integration

**Add flags to `src/rosh/cli.py`:**

```python
parser.add_argument('--test', metavar='INPUT_FILE',
                   help='Test mode: read inputs from file')
parser.add_argument('--test-input', metavar='INPUTS',
                   help='Test mode: comma-separated inline inputs')

# Parse test inputs
test_inputs = []
if args.test:
    with open(args.test, 'r') as f:
        test_inputs = [line.strip() for line in f.readlines()]
elif args.test_input:
    test_inputs = args.test_input.split(',')

# Create interpreter with test mode
interpreter = Interpreter(
    test_mode=bool(test_inputs),
    test_inputs=test_inputs
)
```

### Unit Tests

```python
# tests/test_test_mode.py
def test_test_mode_with_file():
    """Test --test flag with input file"""
    # Create test input file
    with open('test_input.txt', 'w') as f:
        f.write("Alice\n")

    code = '''
    print "What's your name?"
    input name
    print "Hello {name}!"
    '''

    output = run_rosh(code, test_file='test_input.txt')
    assert "Hello Alice!" in output

def test_test_mode_inline():
    """Test --test-input inline inputs"""
    code = '''
    input x
    input y
    print "{x} and {y}"
    '''

    output = run_rosh(code, test_input="foo,bar")
    assert "foo and bar" in output

def test_test_mode_insufficient_inputs():
    """Test error when not enough test inputs"""
    code = '''
    input x
    input y
    '''

    with pytest.raises(RuntimeError, match="No more test inputs"):
        run_rosh(code, test_input="only_one")
```
