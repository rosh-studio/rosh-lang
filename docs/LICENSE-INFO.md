Following the model of Python (Python Software Foundation), Rust (Mozilla/Rust Foundation), and other major open-source projects, the copyright is held by **"Rosh Project"** rather than individual contributors.

This structure:
- ✅ Protects the project's legal interests

- ✅ Individual contributors still retain rights under MIT

## Viewing License in REPL

Type any of these commands in the Rosh REPL to view the full license:

```rosh
license
```

```rosh
help license
```

```rosh
copyright
```

All three commands display:
- Full MIT License text
- Copyright notice
- Trademark notice
- Links to LICENSE file

## Trademark Protection

The **"Rosh"** name and logo are **trademarks of the Rosh Project**.

**What this means:**

✅ **You CAN:**
- Refer to the software as "Rosh"
- Say "built with Rosh" or "powered by Rosh"
- Use the name in documentation and tutorials
- Fork the project (but rename your fork)

❌ **You CANNOT:**
- Suggest official endorsement without permission
- Use "Rosh" in product names implying affiliation
- Use the logo without permission
- Register "Rosh" as your own trademark

**Why?** Just like Python, Rust, Linux, and other open-source projects, we keep the **code free** (MIT) while protecting the **brand** (trademark). This prevents confusion about what's "official" while keeping development open.
