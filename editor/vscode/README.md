# Rosh Language for VS Code

The official VS Code language extension for [Rosh](https://rosh.cloud).

## Features

- syntax highlighting for current Rosh keywords, events, literals, and operators
- interpolation highlighting inside single- and double-quoted strings
- folding for event, conditional, function, repeat, and collection blocks
- snippets for components, functions, collections, events, and games

## Install From Source

From the `rosh-lang` repository:

```bash
cd editor/vscode
./install.sh
```

Reload VS Code after installation.
